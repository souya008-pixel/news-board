# ニュースボード

国内・海外のニュースをまとめて読めて、株に関係しそうなニュースを自動で拾い出すアプリです。
Windows に最初から入っている PowerShell だけで動きます（インストール不要）。

## 起動と終了

- **起動**: `start.bat` をダブルクリック → 黒いウィンドウが開き、ブラウザで http://localhost:8765/ が開きます。
- **終了**: 黒いウィンドウを閉じる（または Ctrl+C）。
- すでに起動中に `start.bat` を実行すると、ブラウザで開き直すだけです。

## スマホで見る（GitHub Pages・おすすめ）

GitHub が20分ごとにニュースと指数を取得して、Web サイトとして公開します。**PC の電源が切れていても見られます。**

- アドレス: `https://<GitHubのユーザー名>.github.io/<リポジトリ名>/`
- Safari の共有ボタン →「ホーム画面に追加」で、アプリのように開けます。
- 仕組み: `.github/workflows/update.yml` が `server.ps1 -Export` でデータ（`data/news.json`・`data/quotes.json`）を作り、`public/` と一緒に公開します。
- `config.json` や `public/` を変更して GitHub に push すると、数分で反映されます。
- 手動ですぐ更新したいとき: GitHub のリポジトリ →「Actions」→「ニュースを更新して公開」→「Run workflow」。

PC で起動するときとの違い:

- ニュースは最大20分ほど前（GitHub の混雑時はもう少し）の情報です。「更新」ボタンは最新の公開データを読み直します。
- 検索とウォッチリストは、取得済みのニュース（直近1〜2日）の中から探します。もっと探したいときは検索結果の「Googleニュースで探す」から。
- 公開サイトなので、アドレスを知っていれば誰でも見られます（ログイン情報などは含みません）。

## スマホで見る（Tailscale）

PC とスマホの両方に [Tailscale](https://tailscale.com/download) を入れ、同じアカウントでログインしておきます。

1. 初回だけ `setup-phone.bat` をダブルクリック（管理者の確認が出たら「はい」）。PC を再起動しても設定は残ります。
2. PC で `start.bat` を起動（黒いウィンドウに「スマホ（Tailscale）: …」と表示されます）。
3. スマホで Tailscale を接続した状態で、ブラウザで表示されたアドレスを開きます（例: `http://laptop-xxxx.tailXXXX.ts.net/`）。
   開けないときは `http://PCの名前/`（例: `http://laptop-xxxx/`）も試してください。IP アドレス（100.x.x.x）では開けません。
4. Safari の共有ボタン →「ホーム画面に追加」で、アプリのように開けます。

- 見られるのは、PC が起動していて `start.bat` の黒いウィンドウが開いている間だけです。
- Tailscale でつながった自分の端末からしか開けません（同じ Wi-Fi の他人からは見えません）。
- 元に戻すには `setup-phone.bat -Remove`（コマンドプロンプトで実行）。

## できること

| 機能 | 内容 |
|---|---|
| カテゴリ別ニュース | トップ / 国内 / 国際 / 経済・マーケット / テクノロジー。NHK、Yahoo!ニュース、Googleニュース、BBC、CNN、NYT、Bloomberg、CNBC など31の配信元 |
| マーケット指標 | 日経平均・NYダウ・ナスダック・S&P500・ドル円・米10年債利回り・WTI原油・ビットコイン。前日比と当日の値動き |
| 株関連の自動判定 | 見出しと概要から「#決算・業績」「#為替」などのテーマと関連銘柄（トヨタ 7203 など）を付け、「株関連」バッジを表示 |
| 株関連ピックアップ | 相場・決算・金利など、株価に影響しそうなニュースを新しさと重要度で8件選んで表示 |
| 注目テーマ / 話題の銘柄 | 直近の記事数ランキング。クリックするとその記事だけを表示。銘柄の ↗ で Yahoo!ファイナンスの株価ページへ |
| ウォッチリスト | 企業名やキーワードを登録すると、Googleニュースから直近7日の記事を集めて表示（話題の銘柄の ☆ からも登録可） |
| 検索 | 絞り込み欄で Enter を押すと Googleニュースを検索 |
| 英語の記事 | 「日本語で読む」で Google 翻訳を通して開けます。「英語の記事」のチェックを外すと非表示 |

ショートカット: `/` 検索、`R` 更新、`1`〜`6` タブ切り替え。
ニュースは10分ごと、指数は3分ごとに自動更新されます。
画面右上のボタンでライト / ダーク表示を切り替えられます。

URL の末尾で表示を指定できるので、ブックマークにも使えます。
例: `http://localhost:8765/#market`（経済・マーケット）、`#theme=fx`（為替の記事）、`#stock=7203`（トヨタの記事）

## カスタマイズ

- **配信元を増やす・減らす**: `config.json` の `feeds` を編集します。
  - RSS の場合: `{ "category": "market", "name": "表示名", "url": "https://…/rss.xml" }`
  - Googleニュースの検索結果を使う場合: `{ "category": "market", "name": "表示名", "googleQuery": "半導体 OR 生成AI when:1d" }`
  - 英語の配信元には `"lang": "en"` を付けます。
- **指数を変える**: `config.json` の `markets`。`symbol` は Yahoo Finance の記号です（例: `^N225`、`JPY=X`）。
- **株関連の判定語・銘柄を追加する**: `public/keywords.js` を編集します（書き方はファイル冒頭に説明があります）。

編集後は、画面の「更新」ボタンで反映されます（ブラウザの再読み込みも必要な場合があります）。

## 注意

- 見出し・概要は各社の RSS を利用しています。記事本文は各社のサイトで読む形です。
- 株関連の判定はキーワードによる自動判定なので、誤判定や見落としがあります。
- 指数・為替は Yahoo Finance の参考値で、遅延があります。投資の判断はご自身の責任で行ってください。
- アプリは自分のパソコンの中で動き、外部からは自分の Tailscale 端末以外アクセスできません。設定（ウォッチリストなど）はブラウザごとに保存されます（PC とスマホで別々）。
- 配信元のサイト側の変更で、一部のニュースが取得できなくなることがあります。その場合は画面の「一部の配信元を取得できませんでした」から確認できます。

## ファイル構成

```
news-board/
├─ start.bat        起動用
├─ setup-phone.bat  スマホ（Tailscale）から開けるようにする初回設定
├─ server.ps1       ニュース・指数を取得して画面に渡すローカルサーバー
├─ config.json      配信元・指数の設定
├─ public/          画面（index.html / style.css / app.js / keywords.js など）
└─ .github/workflows/update.yml  GitHub Pages で公開するための定期実行の設定
```
